# ASTROLAB App Icon Standard
## v1.0 — Silver / Cobalt
2026-11-24 · 参考母版：Interpreter (In)

### 01 / 设计原则
统一采用银白金属底、深石墨色字标、右下钴蓝直角三角。极简、克制，不使用具象插画、额外符号、外部阴影、描边或高光浮雕。应用之间主要通过两字符字标区分，不随意更换底色。
本规范为 Interpreter 所采用的新版家族方向；历史 Bench v0.3 纯色方案保留，不自动覆盖已发布资源。

### 02 / 几何规范
坐标原点为画布左上角，单位为 px。
| 项目 | 标准值 |
| --- | --- |
| 母版 | 1024 × 1024，RGBA |
| 外部留白 | 四边 88 px，透明 |
| 底板 | x=88, y=88, 848 × 848 |
| 左上、右上、左下圆角 | R208 |
| 右下角 | 直角 |
| 品牌三角 | 160 × 160，贴底板右下角 |
| 三角顶点（连续坐标） | (776,936), (936,936), (936,776) |
| 字标中心 | (512,512)，按可见字形包围盒居中 |
| 字标字号 | 590 px（Interpreter 母版） |
| 字标补强 | 4 px 同色描边（仅字形） |
| 字标最大宽度 | 656 px，其他字偶超宽时等比缩小 |

不得拉伸字形，不得改变三角方向，不得将三角改为挖空切角。像素栅格化时右边及下边最后一个像素为 935。

### 03 / 色彩
| 元素 | 色值 |
| --- | --- |
| 字标 | #252A32 |
| 品牌三角 | #2859CC |
| 金属底顶部 | #FCFCFF |
| 金属底底部 | #E0E0E3 |

金属感来自轻微的纵向明度变化，而非摄影纹理或随机噪声。
底板内归一化高度 t = clamp((y-88)/848, 0, 1)。
亮度 v = round(252 - 28t + 5 sin(2πt))，RGB = (v, v, min(255,v+3))。
以实际生成器为准，不添加镜面反射、拉丝噪点或强烈渐变。

### 04 / 字体与字标
使用 ASTROLAB Sans Fresh 0.5 / ASTROLABSans-Regular.ttf 的真实字形。
Interpreter 字标为 In（大写 I、小写 n），不得替换为 IN、in 或通用系统字体。
新应用优先选用具有辨识度的两字符缩写，并在确定后固定大小写。
其他字偶沿用同字体、字号及补强；按可见轮廓居中，超宽等比缩小。
字体原文件仅作为本地生成输入，不随图标规范或公开资源分发。

### 05 / 输出与适配
母版：design/AppIcon.png。
Android：mdpi 48、hdpi 72、xhdpi 96、xxhdpi 144、xxxhdpi 192 px，均使用 Lanczos 缩放。
当前 Android 使用传统 launcher PNG，以尽量保留三圆角一方角。实际启动器可能施加圆形或圆角遮罩；自适应图标适配需单独验证安全区，不能假设所有设备保留右下三角。
macOS：可从 1024 px 母版生成 iconset / ICNS；平台包装不得任意修改母版。
至少检查 32、48、64 px 下的字标清晰度、三角识别度与留白。新字偶应在真机或 Dock 上验收。

### 06 / 可复现生成
本项目 scripts/make-icon.py 为 Interpreter 参考实现，依赖 Python 3 + Pillow。
```sh
python3 scripts/make-icon.py
# 或指定本地字体路径
python3 scripts/make-icon.py /path/to/ASTROLABSans-Regular.ttf
```
默认字体位置：~/astrolab-type/releases/ASTROLAB-Sans-Fresh-0.5/ASTROLABSans-Regular.ttf。
生成器输出母版和 Android 各密度资源。禁止通过截图、AI 重绘或重复缩放旧图标制作新母版。
新应用应从相同参数和真实字体重新生成；新增字偶的尺寸适配需验收。

### 07 / 发布检查
- [ ] 银白底与深石墨字标，钴蓝三角颜色准确
- [ ] 三圆角一方角，三角紧贴右下角
- [ ] ASTROLAB Sans 真字形，大小写正确
- [ ] 小尺寸图标可读、无裁切
- [ ] 应用桌面名称正确
- [ ] 不公开分发字体原文件
- [ ] 真机 / Dock 预览验收
